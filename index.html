GET SET UP

A few steps.
Then start writing.

The download prepares the files. You enable the extension in Chrome once.

The extension currently appears as Google Docs in Chrome. It is an independent tool, not an official Google product.

  1. 1

    Download and run the installer.

    Run Draft-Guide-Setup-2.2.0.exe. It installs for your Windows account without administrator access. Open the setup guide when it finishes.

    The installer is unsigned, so Windows may show an unknown publisher. Checksums are available below.

  2. 2

    Open Chrome’s extensions page.

    Copy this address into Chrome’s address bar, then turn on Developer mode in the top right.

    chrome://extensions
  3. 3

    Choose Load unpacked.

    Select the extension folder below. The installer’s setup guide also gives you a full, copyable path.

    %LOCALAPPDATA%\Programs\DraftGuide\extension

    If your organization disables Developer mode, ask its administrator about installation.

  4. 4

    Make it yours.

    Open the extension → Settings. Paste your reference text and save it. Under Show / hide shortcut, click Change shortcut, press a key, then click Save shortcut. Open your document, click your writing position, and use that shortcut.

GOOD TO KNOW

Before you begin.

How do I update an existing installation?

Run the new installer in the same location, or replace the files in your existing portable folder. Open chrome://extensions, click Reload on the extension, then refresh your document. Keeping the same folder preserves its identity and saved reference text. Do not remove and reinstall the extension just to update it.

Which shortcut can I choose?

Try a function key such as F8, a navigation key such as Insert or Home, or a combination such as Ctrl + Shift + K. Cmd combinations also work when Chrome receives them. Plain letters and typing keys are rejected to protect normal writing. Escape always stops the guide. System shortcuts and keys reserved by Chrome may not reach the extension.

Does it type or generate text for me?

No. It displays reference text you load beforehand. You type it by hand. It does not insert text, generate an essay, or alter document revision history. Moving the caret or pasting pauses tracking; choose the right starting sentence in settings before continuing.

Who can see the hints?

Hints appear in your browser, so anyone viewing or recording your screen can see them while shown. They are not shared as part of the document. This does not make the extension invisible to browser or device management tools.

Where does my reference text go?

It is stored locally in your Chrome profile. The extension does not send it to this website or an AI service. Optional speech uses voices Chrome reports as local, through your system’s selected audio output.

Is this made by Google?

No. Draft Guide is an independent project. The extension’s display name is Google Docs, but it is not affiliated with or endorsed by Google. Google Docs and its product icon belong to Google.
